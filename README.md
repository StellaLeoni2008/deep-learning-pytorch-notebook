## 📌 About

This repository contains the notebooks developed throughout Alura's **Deep Learning with PyTorch** learning path.

During the learning process, I explored the fundamentals of Artificial Neural Networks and Deep Learning using PyTorch, one of the most widely used frameworks for building and training Artificial Intelligence models.

---

## 📚 Learning Path Structure

### 📁 01. Introduction to Neural Networks

Introduction to the fundamental concepts of Artificial Neural Networks using PyTorch.

This notebook explores the main components of a neural network, including tensors, perceptrons, linear layers, and the basic concepts that allow neural models to learn patterns from data.

---

### 📁 02. Training Neural Networks

Focus on the neural network training process.

This section covers concepts related to loss functions, optimization algorithms, gradients, backpropagation, validation, and performance evaluation during training.

---

### 📁 03. Recurrent Neural Networks

Introduction to Recurrent Neural Networks (RNNs).

The notebooks in this section explore architectures designed for sequential data processing, providing an understanding of applications involving text, natural language processing, and time series.

---

### 📁 04. Convolutional Neural Networks

Study of Convolutional Neural Networks (CNNs).

This section covers fundamental computer vision concepts, including convolutions, pooling, feature extraction, and image classification using PyTorch.
